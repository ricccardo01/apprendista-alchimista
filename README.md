# L'Apprendista Alchimista

Progetto per l'esame di Metodologie di Programmazione (UNICAM, AA 2025/26).

È un gioco di ruolo a turni in Java con interfaccia grafica in JavaFX. Si gioca nei panni di un apprendista alchimista che esplora le rovine del laboratorio del suo maestro e combatte usando Zolfo, Mercurio e Sale.

Più dettagli sul progetto sono nella Wiki.

## Come eseguirlo

Serve Java 17 o superiore per far partire Gradle. Se manca Java 25, Gradle lo scarica in automatico.

```
./gradlew build
./gradlew run
```

Su Windows si possono usare anche `gradlew.bat build` e `gradlew.bat run`.
